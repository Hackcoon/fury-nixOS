## HOW TO READ (compiled vs hot-reload)

- `config.def.h` = compiled in. Edit → `make && sudo make install` (or `make clean install`), then `Super+Shift+r` to restart dwm (keeps tags/windows).
- `sxhkdrc` = hot-reloadable. Edit → `Super+Escape` (pkill -USR1 sxhkd).
- `keybindings.txt` is GENERATED by `scripts/gen-keybinds` from the annotated `keys[]` table — edit the trailing `/* ... */` comments in `config.def.h`, not the txt.
- Cheatsheet: `Super+h` (dwm compiled) or `Super+slash` (sxhkd) → `~/.config/suckless/scripts/help` (rofi).
- sxhkd only binds `a-z` / ASCII reliably — remap for non-US layouts.
- Mango parity notes inline: many chords were deliberately aligned with `~/nixos-backups/mango-ultimate-hotkeys.md`.
